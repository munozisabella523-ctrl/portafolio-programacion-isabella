## Proyectos

- **Mundo Ciencia:** aplicación académica PHP y MySQL presentada con su equipo. El código fuente recibido está en [`mundo-ciencia/mundo/`](mundo-ciencia/mundo/); los archivos de usuarios y volcados de datos quedan excluidos del repositorio. La página descriptiva es [`mundo-ciencia.html`](mundo-ciencia.html). Para ejecutar la aplicación se necesita un servidor con PHP y MySQL y una base de datos configurada. GitHub Pages publica el portafolio estático, pero no ejecuta PHP.
- **Promedio académico:** práctica guiada con HTML, CSS y JavaScript. Calcula tres notas ponderadas y valida que los porcentajes sumen 100 %. Código: [`notas.html`](notas.html), [`notas.js`](notas.js) y [`styles.css`](styles.css).
- **Agenda de estudio:** práctica guiada con HTML, CSS y JavaScript. Permite agregar, completar y eliminar tareas, y guardarlas en el navegador mediante localStorage. Código: [`agenda.html`](agenda.html), [`agenda.js`](agenda.js) y [`styles.css`](styles.css).

Las prácticas nuevas se prepararon con asistencia de IA como material de aprendizaje. Deben ser estudiadas, adaptadas y explicadas antes de presentarlas como evidencia de aprendizaje propio.

## Archivos del portafolio

Abre `index.html` o visita la versión publicada. No se necesitan instalaciones ni compilación. `hoja-de-vida.pdf` contiene la hoja de vida de una página, con foto y enlaces al portafolio y al perfil de GitHub. La foto aparece únicamente dentro del PDF.

La agenda guarda datos solo en el navegador; no sincroniza entre dispositivos.
